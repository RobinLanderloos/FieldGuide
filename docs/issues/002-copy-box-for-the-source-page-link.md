# Copy box for the Source page link

**Type:** AFK  
**User stories:** 22, 23

## State

Open

## What to build

A link button in the Guide window header opens the Copy box with the Source page URL selected for Ctrl+C. Bare URLs inside Section text are shown as clickable links that open the same Copy box.

## Acceptance criteria

- [ ] Link button opens the Copy box with the full URL highlighted and focused
- [ ] Esc or clicking away closes it
- [ ] URLs in Section text are detected (Markup) and clickable
- [ ] Tests cover URL detection; smoke test opens the Copy box
