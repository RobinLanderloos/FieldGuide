# Sections are free-form; only Talents and Rotation are typed

Any `## Heading` in a Guide Import becomes a section, shown as written (paragraphs, bullets, numbered lists). Only two blocks have a strict syntax that the addon interprets: `## Talents` (the Leveling Path) and `## Rotation` (text split by level range, where the addon shows the range for the player's current level plus any unranged blocks such as AoE). We rejected a fixed list of sections (Overview, Gear, Races, ...) because guides are structured differently, and forcing content into categories loses the author's organisation.
